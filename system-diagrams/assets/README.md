# PureLink System Diagram Library — v1.0

Master library for isometric system diagrams used in PureLink product manuals.
Created 12 October 2026. Owner: Robin Cullen (Technical Director).

## The golden rule
**Files in `masters/` are never edited.** Every new diagram is produced by re-rendering a master
from the code in `code/` with options or additions switched on, and saving the result *outside* `masters/`.
A master can always be reproduced exactly by running `code/render_all.py` (checked against `MANIFEST.txt`).

## Folder structure
| Folder | Contents |
|---|---|
| `masters/rooms/` | Empty room views (furniture and displays only), PNG + SVG |
| `masters/classroom_system/` | Classroom system diagrams, three touch panels × Clean / X-ray, PNG + SVG |
| `code/rooms.py` | Generator for the room masters (one function per room, variants as options) |
| `code/classroom_system.py` | Generator for the classroom system diagrams (products, cabling, labels) |
| `code/render_all.py` | Re-renders every master into `build/` for checking |
| `fonts/` | Barlow (SIL Open Font License), embedded into every SVG |
| `reference/` | Product renders and the original layout sketch / style reference |
| `MANIFEST.txt` | SHA-256 checksum of every master file |

## Visual standard
- Isometric (30°) view; back wall and left wall shown, room cut away at the front.
- Palette: walls #F5F6F8 / #ECEEF1, floor #E4E7EB, devices #3F4145–#5A5C60, PureLink blue #3C6CB4, badge blue #6084C0.
- Font: Barlow (close match to PureLink silkscreen). Titles 30–34 px bold, subtitles 17–18 px.
- Canvas 2000 px wide; PNG exported at 2× (4000 px). SVGs are fully self-contained.
- Scale: touch panels at true scale; other PureLink devices drawn at about 1.8× for readability.
- PDF exports: A4. Language: British English.

### Cable colour standard
| Colour | Hex | Meaning |
|---|---|---|
| Magenta | #C85FD8 | HDBaseT (video, USB, control) |
| Red | #E0393E | HDMI — video only |
| Blue | #3C6CB4 | USB-C |
| Green | #2FA86A | LAN / PoE |
| Black | #1E1F22 | Relay control |

### View modes (system diagrams)
- **Clean:** only cabling visible in the finished room; devices hidden in ceilings/walls are greyed out with dashed labels.
- **X-ray:** concealed runs dashed; ceiling void shown as a dashed band; desk and chair translucent so under-desk cabling is visible.

## Re-rendering
```
pip install cairosvg
# install fonts/barlow-latin-*.woff2 (or Barlow TTF) on the system for PNG text
python code/render_all.py      # writes to build/, never touches masters/
```
