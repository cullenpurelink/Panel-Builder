Product Icon Generator

Renders a small isometric "cartoon box" icon for every product currently listed in data/library/manifest.json — add a product to the library and it appears here automatically next reload, no code change needed. The front/rear panel is a flat 2D drawing (chassis bar + realistic port-shape approximations) mapped onto the isometric face with a single affine transform; the top/side faces are plain flat-shaded polygons behind it, with the "PureLink" wordmark sheared onto the top face. Left-facing views are a true mirror of the right-facing geometry (never upside-down); the front panel content and the top wordmark each have their own independently-tuned affine map so text is never reversed, upside-down, or rigidly rotated (which reads as italic). Re-run this page any time the source JSON changes; nothing here is hand-edited afterwards. "Save to library" writes straight into system-diagrams/assets/products/ via the dev server — only works when opened through start.bat/http://localhost:8743/..., not as a file:// page.
