PURELINK

System Diagrams

Module 2 of the PureLink design & production suite — a viewer onto the real PureLink System Diagram Library v1.0 master register (7 masters, see the full README). New diagrams are still authored via the "PureLink System Diagrams" Claude Project and the rooms.py / classroom_system.py generators — not from this page. See this module's README for how the pieces fit together.

Visual standard

Isometric (30°) view, back and left walls shown, room cut away at the front.

Font: Barlow. Canvas 2000px wide, PNGs exported at 2×. SVGs are fully self-contained.

Touch panels at true scale; other devices drawn at about 1.8× for readability.

Cable colour standard

Magenta — HDBaseT (video, USB, control)
Red — HDMI, video only
Blue — USB-C
Green — LAN / PoE
Black — Relay control

View modes

Clean: only cabling visible in the finished room; concealed devices greyed out with dashed labels.

X-ray: concealed runs dashed, ceiling void shown as a dashed band, desk/chairs translucent so under-desk cabling shows.

Room masters — M-01 to M-06

Empty room views (furniture and displays only). Generated by rooms.py.

Classroom system diagrams — M-07

Touch-panel systems: KVM TX under the teacher desk, RX in the ceiling, projector, PEX-110 relay screen control. Generated by classroom_system.py.
